# Jc Portrait

An experimental interactive portrait project exploring identity, storytelling, visual design, and creative web interactions.

## Overview

Jc Portrait is a front-end concept that presents a person through multiple perspectives and interactive sections. It combines editorial-style layout, motion, typography, and narrative to create a more personal web experience.

## Built with

- HTML
- CSS
- JavaScript
- Responsive web design
- Accessibility-minded interaction patterns

## Run locally

```bash
git clone https://github.com/saitejav668-spec/Jc-portrait-.git
cd Jc-portrait-
```

Open `index.html` in a browser, or serve the folder with any local static server.

## Project structure

- `index.html` — page structure and content
- `style.css` — visual design and responsive styles
- `app.js` — interaction and behavior
- `assets/` — project assets
