MIND & CURIOSITY01 / 08

先理解，再決定相信什麼。

jc 習慣追問定義、原理與差異。從心理動機到顯示器技術，一個名詞的背後，往往還有另一層想弄懂的結構。

追問原理跨領域聯想保留判斷

側寫觀察

好奇心很旺盛，也正在練習替深究設定一個停靠點。

對話裡的線索

會把 AG／AF／AR 的表面處理，連到自己手機霧面保護貼在陽光下的使用經驗；也會從 Coding 與 Programming 的差異，追問整個程式工作的範圍。

抽象概念如果能接上實際經驗，就比較容易成為自己的理解。

一個值得留意的拉扯

有時真正困難的是判斷「現在需要懂到哪裡」。jc 曾主動要求技術說明大概就好，因為怕一追究就擱置手邊的重要工作。

一個適合她的節奏：先回答眼前問題，把延伸問題記下來，留給有餘裕的時候。

關於人格標籤

jc 曾以 INTP、INFJ 與認知功能框架探索自己。這些可以是自我描述的語言；這份側寫以她實際分享的偏好與行動為主，不把四個字母當成人的定論。

LANGUAGE & NUANCE02 / 08

準確之外，還要有分寸。

日文業務與會議口譯是 jc 的專業日常。她在意一句話是否忠於原意，也在意對方會怎麼聽、這個場合需要多大的禮貌距離。

商務日文會議口譯語感與語境

側寫觀察

語言對她來說，同時是訊息、立場與人際關係的安排。

已經走過的路

已取得日文檢定 N1，持續練習商務溝通、公司介紹與口語表達。即使有相當基礎，仍會細看時間範圍、主詞立場、敬語與詞語搭配。

翻譯歷史人物的文字時，也曾特別強調尊重原作者的表達，不輕易把不熟悉的措辭當成錯誤。

真正想再練好的部分

她曾說，日文表達時比較容易卡在抓出核心訊息、避免放入過多細節。資訊一多，說話節奏就容易跟著急起來。

因此，比增加漂亮詞彙更貼近當下需求的練習，是先說結論，再補對方做判斷需要的背景。

喜歡怎樣的協作

日文要自然、得體、精確；英文則希望維持自己能掌握、能實際拿去使用的程度。需要保留的原意，不能被潤稿的流暢感沖掉。

WORK & COORDINATION03 / 08

站在不同專業的交會處。

她的工作經驗橫跨日文溝通、專案協調與產品知識。從工業電腦走到顯示相關產業，需要把客戶的問題帶回內部，也把技術回覆轉成對方能使用的資訊。

跨部門協調需求釐清技術理解

側寫觀察

側寫中的一條主線：她在意事情有沒有被理解，也在意事情最後能不能往前走。

她實際處理的問題

會議口譯與紀錄、商務書信、專案進度、規格確認，以及客戶與技術人員之間的資訊往返。工作既需要語言，也需要把模糊問題整理成可確認的項目。

仍在建立的能力

進入顯示產業後，持續學習 LCD、Touch、TCON、LED Driver 與介面規格。遇到規格書判讀失準時，會回頭問自己用了哪些線索、哪個假設需要查證。

現階段把「文件明確寫的」「依線索推測的」「需要請技術確認的」分清楚，比急著每一題都有答案更有用。

職涯上的偏好

她曾對專案管理、協調、營運與分析類角色表達興趣；對純粹以銷售目標為中心的工作，則有自己的考量。

這呈現的是目前談過的偏好，未必是未來唯一的方向。

LEARNING & SYSTEMS04 / 08

把懂了一點，慢慢變成會用。

jc 從社會組背景跨進技術知識與程式學習。她會問很基礎的操作，也會追到概念的邊界；學習的跨度，常常比線性課綱更大。

Python 入門具體例子筆記與清單

側寫觀察

她需要一條能看見「自己現在站在哪裡」的學習路徑。

目前能確認的學習接觸

接觸過 Python 的條件判斷、布林值與 type()，使用過 Google Colab，也開始認識 VS Code 的終端機。

網站方面，已實際碰過首頁檔案、資源路徑、手機與桌機差異，以及 GitHub 的 Commit、Push 與 Pages。這些是已接觸和操作過的範圍，不等於已能獨立完成整套開發。

記憶如何落地

喜歡清單、實際書寫與整理錯誤，也使用 Obsidian、Notion 等工具。紙本的可見性與數位筆記的即時更新，各自解決不同問題。

模板太多時，她也會感到選擇困難。對她有用的系統，需要讓下一步更清楚，而不是多一項要維護的東西。

比較適合的說明方式

先給可操作的一步，再解釋剛才發生什麼；用對照、具體例子與必要的術語建立連結。忙碌時先處理眼前需求，有時間再往下挖。

AESTHETICS & SENSIBILITY05 / 08

有秩序，也要有一點性格。

jc 對色系、模板與字體有明確感受。她偏好低彩度、清楚的層次與留白；當畫面太老派、太制式，或偏離給定參考時，會直接指出來。

低彩度清楚的層次字體有感

側寫觀察

好看需要具體：是哪個字體、哪種版型、哪一份參考。

她反覆提過的視覺偏好

莫蘭迪色系、灰、褐、軍綠、海軍藍與米色，也曾指定黑灰白基調。相較於七彩裝飾，她更在乎配色與版面是否一致。

炭黑石灰軍綠海軍藍灰褐灰紫
字體也是語氣

她曾偏好非襯線字體，後來特別指定芫荽體，並提供字型檔。本頁的中文標題與側寫筆記使用她提供的芫荽體，長段落搭配系統字體維持閱讀清晰。

她會直接說的事

參考圖不能被另一個模板替代；畫面上的內容也不能為了好看而改錯。這份要求同時落在形式與資訊準確性上。

MAKING & EXPERIMENTS06 / 08

想像出現了，就想讓它能被打開。

她會把旅行規劃做成互動網站，也會把帶有日本神話意象的居所推向 3D 空間。工具從 Canva 延伸到 AI 協作與網頁，創作的媒介也跟著擴大。

互動網頁空間想像AI 協作

側寫觀察

她會追問：能操作嗎？手機上呢？別人能打開嗎？

最近的創作方向

互動式旅行行程、個人側寫網站、簡報視覺，以及帶有水流與霧氣的 3D 居所。她在意作品既能傳達氣氛，也要有真正可用的互動。

創作中的品質標準

做空間時會問是否可居住、結構是否合理；做網站時會問圖片、音訊、RWD 與分享連結有沒有正常運作。她要看得見、點得到，也傳得出去。

與 AI 合作的方式

jc 會提供參考、指出錯誤、要求重做，也會追問程式與部署背後的概念。她有明確的成品判斷，同時仍在累積獨立排查技術問題的能力。

LIVING & RHYTHM07 / 08

腦袋之外，也有自己的拍子。

閱讀、K-pop、舞蹈、旅遊與生活規劃，構成她工作之外的日常。她喜歡理解事情，也需要能安心享受、放空與恢復節奏的時間。

K-pop 舞蹈閱讀旅行規劃

側寫觀察

喜歡一件事，可以只是因為那段時間很快樂。

舞蹈的意義

長期喜歡韓國流行音樂，也會拆解舞步、反覆練習。她曾說，參加課程最重要的是享受那段時間，對和其他學生競爭沒有同樣的興趣。

閱讀與想像

喜歡大腦科學與學習方法，也讀日文小說；過去尤其喜歡懸疑、恐怖題材。閱讀既提供理解世界的素材，也能成為退回自己節奏的空間。

讓生活有一點可掌握的秩序

她會認真整理旅行動線、交通、住宿與待辦，把複雜資訊轉成一份能拿來使用的計畫。也談過减少社群依賴、保留閱讀與實體活動的時間。

VALUES & RELATIONSHIPS08 / 08

保有判斷，也保有溫度。

jc 會質疑沒有充分理由的權威，也對人的動機、關係中的不舒服與理解的可能性保持興趣。理性與感受，常常同時出現在她的問題裡。

獨立判斷關係的界線開放但查證

側寫觀察

她希望對話有觀點、有理由，也容得下修正。

怎麼看待不同觀點

曾自述偏向科學實證，也逐漸願意理解某些精神性實踐對人的主觀意義。這裡呈現的是她的態度變化，不代表相關理論已獲得科學證實。

關係裡在意的事

她在意相處是否消耗、溝通是否真誠，也會思考嘲弄、幸災樂禍等行為背後的心理。被理解與維持界線，都是反覆出現的題目。

對話最好有一點人味

喜歡自然、直接、有觀點的回應，也容得下吐槽與幽默。解釋需要清楚，別把每個問題都包成一篇沒有立場的標準答案。
